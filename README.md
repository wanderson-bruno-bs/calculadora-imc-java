#  Calculadora de IMC em Java

Desenvolvida durante os meus estudos na liguagem Java.

O programa solicita ao usuário sua altura e peso, calcula o Índice de Massa Corporal (IMC) e informa a classificação correspondente ao resultado.

## Funcionamento

O cálculo utilizado é:

IMC = peso / (altura × altura)

O programa recebe os dados pelo console e exibe o resultado do IMC com duas casas decimais, seguido da classificação correspondente.
